## 大会が終わったあとの手順（人が保存する方式）

FIS サイトの利用規約は自動取得（スクレイピング）を禁じているため、PDF は Van さんのパソコンで、
ブラウザから通常の閲覧として保存する。Claude Code に Chrome を操作させて保存してもよい（人が見て保存するのと同じ操作）。

1. FIS の大会ページ（Calendar & Results → 大会 → 該当レース）を開き、添付の
   「Results - Qualification」「Results - Final Run 1」「Results - Final Run 2」
   （選手権形式は「Results - Qualification Run 1 / Run 2」）を男女分保存する。
   「Results - Final」（総合サマリー）、Start List、Bracket（デュアル）は不要。
2. 上の表の保存先フォルダに、次の名前で置く。
   `<会場>_<男子|女子>モーグル<予選|予選1|予選2|決勝1|決勝2>_<codex>.pdf`
3. Claude Code に「README の手順で ○○大会を取り込んで」と頼む。ETL が回り、検証レポートが出る。
4. エラー 0 を確認して `--accept-rounds` で基準に登録し、画面で確認してから公開する。

FIS サイトの HTML 結果との照合（第5層）は、新しい大会の分だけ `python -m etl.build --fis --fis-filter 2026-27` で行う
（既に照合済みの大会は結果を記録済みなので再取得しない）。

## 26/27 の規則改定

シーズン開始前にジャッジハンドブックと DD 表の改定版を `モーグルルール/` に置き、`etl/rules/rulesets.json` に
`2026-27` の版を追加する（`2025-26` をコピーして変更点だけ直す）。追加していないと ETL が「規則版が無い」と止まる。
